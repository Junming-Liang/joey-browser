## 环境与范围

运行验证使用桌面 Chromium 与 WebKit、手机触控尺寸及专用浏览器存档；公网验证使用实际 HTTPS 网关。结果不代表全部实体手机或所有完整对局已验收。

程序保持已接受的 WASM SHA `9b3d37007d31af4db92674061306ba7a57c2d848a5aab964a8736b6fbf13481e`。轻量包仅改变声明过的卡图和 PCM，派生块的精确还原与原始档案的逐字节无损是不同口径。

## 资源与基础流程验证（v0.2.0）

| 检查 | 已核实范围 |
| --- | --- |
| 编码与来源 | 原始档案身份固定；458 个块回解与派生字节一致；非像素／非 PCM 区间及目录不变 |
| 完整安装 | 两引擎读取、保存并验证全部 458 块；真实截断后从压缩偏移 4096 继续 |

| 公网 | 两引擎实际读取两档卡图／音频，校验内容；原版启动与隔离响应头通过 |
| 发布 | 24 项部署离线测试；固定原画包、旧索引、解码器与代码校验；失败恢复及其他服务保护 |

完整游戏测试的最后呈现窗口为 30 FPS，场景进入期间仍记录了秒级最大间隔。不能将窗口帧率或音乐测试解释成“整个游戏从不发生卡顿”。

同一 Chromium 卡组界面截图的原画与轻量像素一致；该检查只针对一个实际场景。轻量音频每个 int16 样本误差上限为 4，弱信号文件的相对 SNR 可能明显低于大音量样本，量化边界检查不替代所有素材的人工试听。

## 本次源码同步验证

公开源码目录单独运行语法、来源、读取契约、PCM 和部署检查；保留原游戏输入与浏览器数据的分发排除规则。浏览器脚本使用标准 Playwright 依赖和 `JOEY_CHROMIUM_PATH`。

兼容补丁须对固定 Theseus 提交干净应用。源码同步未重新执行整个 Rust 转换／编译，也不替换原来的性能或手机验收结论。

## 仍待验证

- 完整胜利、失败、奖励及全部卡牌效果的持续覆盖。
- 全部重放、命名路径与中文输入法。
- 实际 Android／iOS 设备、存储压力和网络条件的持续测试。
- 更多轻量卡图边缘、低音量声音与循环接缝的感知质量。

首版记录保存在 [verification.json](verification.json) 与 [v0.1.0 发布说明](../releases/v0.1.0.md)，不将不同版本和缓存条件的启动时间直接计算为性能提升。

## 本地完整部署包

本次新增的本地打包与安装工具已使用完整原输入和已接受程序实际验证：解包到独立新目录、从 v2 无损包还原三个原档案、核对 EXE／DAT／WASM 哈希并生成独立配置。Chromium 和 WebKit 均完成启动、持续呈现至少 120 帧、音频上下文处于 running；重复安装拒绝覆盖已有配置。此项使用桌面引擎及手机尺寸，不代表实体手机或完整对局验收。原游戏附件保留在本机。详情见 [verification-v0.2.0.json](verification-v0.2.0.json)。

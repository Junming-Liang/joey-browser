# v0.1.0 · 首个浏览器版本

对应当前运行版本：`20261005-234225-b8043abd`。

城之内原版程序已在浏览器本地运行，保留原游戏界面、决斗规则与AI，提供手机触屏操作、音频输出、本地存档和资源缓存。

首版包含：

- 原程序WebAssembly兼容运行、后台线程及共享内存。
- 原800×600画面适配手机窗口。
- 默认约50MB首次压缩下载，完整资源安装可选。
- 资源及程序断点保存，短暂断网自动重试，刷新后续传。
- 程序和已准备资源的本机缓存复用，存档独立保存。
- 已观察字体参数、原卡牌回调入口和客户端像素转换的兼容修复。

验证：Chromium/WebKit原对话、猜拳与首张卡牌流程；两引擎断网/刷新续传、损坏缓存恢复及存储不可用回退；可信公网WebKit实际续传和缓存重开。用户在iPhone Safari上反馈当前体验已比较流畅。

GitHub版本包含源码、兼容补丁、构建输入清单与验证摘要。原游戏安装文件、资源档案、转换后的游戏程序、服务器密码及个人存档未包含。

完整胜利/奖励、所有卡牌效果、重放命名、文字输入和更多真实设备仍需验证。参考哈希及详细范围见version.json和docs/VERIFICATION.md。

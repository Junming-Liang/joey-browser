# v0.3.0 — 好友联机、双语字幕与收藏卡

本版在浏览器原版运行时上增加房间码好友对战、按语音播放同步的中英字幕，以及凉茶、年糕、大葱、猴子、仙人掌五张收藏卡。

- 设置中的中英字幕默认关闭，可随时开关。
- 收藏卡通过胜利奖励收集。凉茶成功结算或四怪成功召唤后，播放各自主题演出并进入原版胜利结算；只限单人使用。
- 浏览器、运行时与服务器共同阻止收藏卡用于联机；原卡组继续沿用原规则。
- 原资源包与缓存继续复用，五张卡另需约 1.1 MB 压缩增量。
- 修复游戏并发加载脚本被父级低频限额误限流的问题。

已在 Chromium 和 WebKit 验证真实收藏卡触发、字幕及公网建房、加入和互换回合；Chromium 完成领取收藏卡、入库存档和重启。实体手机、全部卡效及完整联网胜利领奖仍需持续覆盖。详见 docs/VERIFICATION.md。

`joey-browser-v0.3.0-complete.tar.gz` 是可自行部署的完整归档；校验后按 docs/LOCAL-DEPLOYMENT.md 设置。原游戏内容保留原权利人声明，项目 MIT 不替代其许可。

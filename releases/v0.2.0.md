# Joey Browser v0.2.0

对应运行版本 `20261013-105914-175e2127`。

完整资源安装新增轻量档约 180 MB，保留原画原声档约 228 MB。轻量档仅对卡图和 PCM 做有限精度压缩，UI、文字、字体、背景、卡背、目录偏移及采样布局保持原样。普通按需模式和已有完整缓存继续复用，不强制重新下载。

同步全卡与 45 套兼容卡组、存档锁和备份保护、键盘／退出处理、GDI 兼容修复、取消与对象释放，以及受控发布回滚工具。

源码增加独立 Worker 整数 Brotli 解码、三种包格式、质量选择与缓存隔离检查，并整理构建部署和第三方来源文档。

项目自有代码与文档采用 MIT 许可，第三方组件保留各自版权和许可说明。

两引擎完成 458 块安装校验、断点续传、原版缓存复用、卡组界面持续音乐及真实公网读取／启动检查；这些是桌面 Chromium／WebKit 触控尺寸测试，完整对局与全部真机路径仍需持续验证。

发布仅含源码、声明许可的第三方解码器和验证摘要。原 EXE、DAT、转换后的游戏程序、完整资源包、服务器凭据和玩家存档由部署者自行准备，不附带在源码发布中。
